MY LIFE PLANNER — FIRST VERSION

FILES
- index.html: page structure
- style.css: appearance and responsive layout
- app.js: planner interactions and IndexedDB/local storage
- manifest.json: installable PWA settings
- service-worker.js: offline file cache
- icon.svg: app icon

PUBLISH WITH GITHUB PAGES
1. Create a PUBLIC repository named my-digital-life-planner.
2. Unzip this folder on your computer.
3. Open the repository on GitHub.
4. Select Add file > Upload files.
5. Upload the six files above (not the enclosing folder or ZIP).
6. Commit the upload to the main branch.
7. Open Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Select Branch: main and folder: /(root), then Save.
10. Wait a few minutes and open the Pages URL shown on that screen.

OFFLINE / INSTALL
- First open the published site while online and allow it to finish loading.
- In Chrome, use the browser menu > Install app or Add to Home screen if offered.
- Then test by turning on airplane mode and reopening the planner.
- Planner entries are stored in that browser on that device. They do not sync to other devices.
- Export/backup and cloud sync are not included in this first version.

IMPORTANT
This is a learning prototype, not a secure service for sensitive information. Do not store counselling notes, client details, passwords, financial secrets or other sensitive personal data in it.
