NEW FEATURES
- Year at a glance with yearly theme, three annual goals and dated milestones.
- Home inventory, maintenance reminders and important contacts.
- Weekly overview showing dated tasks and calendar events for each day.
- Routines with custom steps and daily completion checkboxes.
- Finance tracker with monthly budget, income, expenses, savings goals, subscriptions and recurring bill list (AUD).
- Travel planner with trip dates, booking notes, packing checklists and itinerary entries.
- Focus timer with adjustable session length, pause and reset.
- Global search for tasks, projects, lists, trips, milestones, events and notes.
- Quick-add task button.
- Dashboard card visibility settings.
- JSON backup download and restore.
- Meal ingredients can be added to the grocery list automatically.
- Meals and workouts also appear in the relevant daily and weekly overviews.
- Project tasks can be added inside a project and remain connected to the global task list.
- Choose an earthy, sage, clay or sand theme and print the current section.

IMPORTANT DATA NOTES
- Existing IndexedDB database name and store are preserved. Existing planner data is merged with defaults when loaded.
- The app still stores data locally in this browser. JSON backup/restore is included, but automatic cloud or cross-device synchronisation is not.
- Export a backup before updating as a precaution.
- Finance figures are manually entered and are not connected to bank accounts.
- Search and quick-add work within the local planner data.
